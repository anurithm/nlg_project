# nlg_project
# 🤖 Natural Language Generation (NLG) Text Generator

## 📌 Project Overview
This project is an **AI-based Natural Language Generation (NLG) system** that generates human-like text from user-provided prompts.  
It uses a **pre-trained Transformer model (GPT-2)** to produce meaningful and coherent text automatically.

The application is deployed as a **web app using Streamlit**, making it easy to interact with and demonstrate.

---

## 🎯 Objectives
- To understand and implement Natural Language Generation
- To generate readable and meaningful text using AI
- To deploy an NLP model as a web application
- To gain hands-on experience with Transformer models

---

## 🧠 What is Natural Language Generation?
Natural Language Generation (NLG) is a subfield of **Natural Language Processing (NLP)** that focuses on generating text that resembles human writing from structured or unstructured input data.

---

## 🛠 Technologies Used
- **Python**
- **Hugging Face Transformers**
- **GPT-2 Model**
- **PyTorch**
- **Streamlit**
